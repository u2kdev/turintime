# TTPU Timetable

Расписание занятий **Турниского политехнического университета в Ташкенте** — веб-приложение
и Telegram-бот в одном процессе.

Данные берутся из открытого расписания EduPage (`https://ttpu.edupage.org/timetable/`)
через публичный JSON-API без браузера и автоматически обновляются по расписанию.

```
┌───────────────┐   JSON API   ┌───────────┐   SQLite   ┌───────────────┐
│  EduPage      │ ───────────► │  turin    │ ─────────► │  /api/*       │
│  ttpu.edu...  │              │  sync.py  │            │  FastAPI      │
└───────────────┘              └───────────┘            └───────┬───────┘
                                                               │
                                         ┌─────────────────────┴─────────────────────┐
                                         │                                           │
                                   веб-приложение (PWA)                      Telegram-бот
                                   offline-first, RU/EN                      уведомления
```

---

## Возможности

### Веб-приложение
* **Расписание по группам, преподавателям и аудиториям** — неделя или день.
* **«Сейчас идёт / Далее»** — подсветка текущей и следующей пары, прогресс занятия,
  обратный отсчёт. Считается на клиенте, поэтому живёт без перерисовки страницы.
* **Офлайн-режим (PWA)** — расписание скачивается на устройство (localStorage +
  service worker) и открывается без интернета. См. раздел
  [«Как работает офлайн»](#как-работает-офлайн).
* **Два языка** — русский и английский, переключаются мгновенно.
* **Светлая и тёмная темы**, включая режим «Авто» по системной настройке.
* **Поиск** по группам, преподавателям и аудиториям.
* **Устанавливается на телефон** как обычное приложение (Add to Home Screen).
* Без сборки: чистые HTML/CSS/JS, самохостинг шрифтов, `gzip`.

### Telegram-бот
* Выбор группы с поиском и постраничным списком.
* `Сегодня`, `Завтра`, `Вся неделя`, `Ближайшая пара`.
* Расписание преподавателя и аудитории.
* **Утренний дайджест** — пары на день в заданное время.
* **Напоминание перед парой** — за N минут до начала.
* Настройки уведомлений меняются прямо в чате.

## Быстрый старт

Нужен **Python 3.11+** (используется `zoneinfo`).

```bash
git clone https://github.com/u2kdev/turintime.git
cd turintime

python -m venv .venv
.venv\Scripts\activate          # Windows
# source .venv/bin/activate     # Linux / macOS

pip install -r requirements.txt
copy .env.example .env          # Windows   (cp .env.example .env на Linux/macOS)
```

Откройте `.env` и впишите токен бота (необязательно — без него веб-приложение
работает полностью):

```dotenv
BOT_TOKEN=123456789:AA...          # токен от @BotFather
BOT_USERNAME=your_bot              # без @, нужен только для ссылок в интерфейсе
```

Запуск:

```bash
python main.py           # веб-сервер + бот
python main.py update    # только скачать расписание и выйти
```

Приложение будет на <http://localhost:8000>.
Интерактивная документация API — <http://localhost:8000/api/docs>.

> Первый запуск скачивает расписание с EduPage (несколько секунд) и складывает его
> в `data/timetable.db`. Дальше обновление идёт фоном каждые `REFRESH_HOURS` часов.

### Загрузка шрифтов и иконок (только при изменении дизайна)

```bash
python scripts/fetch_fonts.py    # скачивает woff2 в web/assets/fonts
python scripts/make_icons.py     # рисует иконки PWA в web/icons
```

## Настройки

Все параметры читаются из `.env` (полный список — в `.env.example`).

| Переменная | По умолчанию | Назначение |
|---|---|---|
| `BOT_TOKEN` | — | Токен бота от [@BotFather](https://t.me/BotFather). Пусто → бот выключен. |
| `BOT_USERNAME` | — | Имя бота без `@`; из него собирается ссылка `https://t.me/<username>`. |
| `BASE_URL` | `http://localhost:8000` | Внешний адрес приложения (ссылки, PWA). |
| `HOST` / `PORT` | `0.0.0.0` / `8000` | Где слушает сервер. |
| `ADMIN_TOKEN` | — | Токен для `POST /api/refresh`. Пусто → доступ только с localhost. |
| `EDUPAGE_ORIGIN` | `https://ttpu.edupage.org` | Источник расписания. |
| `SCHOOL_NAME` / `SCHOOL_SHORT` | TTPU | Название в интерфейсе. |
| `TIMEZONE` | `Asia/Tashkent` | Часовой пояс для «сейчас» и рассылок. |
| `REFRESH_HOURS` | `6` | Как часто перекачивать расписание. |
| `REFRESH_ON_START` | `true` | Обновлять при старте сервера. |
| `RUN_BOT` | `true` | Выключить бота, оставив веб-приложение. |
| `DAILY_DEFAULT_TIME` | `07:30` | Время утреннего дайджеста по умолчанию. |
| `REMINDER_MINUTES` | `15` | За сколько минут предупреждать о паре. |

### Настройка Telegram-бота

1. Напишите [@BotFather](https://t.me/BotFather) → `/newbot` → задайте имя и username.
2. Скопируйте токен вида `123456789:AA...` в `BOT_TOKEN`.
3. Впишите username (без `@`) в `BOT_USERNAME` — тогда в веб-интерфейсе появится
   кнопка «Открыть бота».
4. Перезапустите `python main.py`. В логе появится `Telegram-бот → включён`.

Бот работает через long polling, отдельный вебхук и домен не нужны.

Если запущено несколько экземпляров приложения, бот должен быть включён **только на
одном** (`RUN_BOT=false` на остальных) — иначе Telegram вернёт конфликт polling.

## API

Базовый префикс — `/api`. Формат — JSON.

| Метод | Путь | Описание |
|---|---|---|
| `GET` | `/api/health` | Жив ли сервис и готова ли база. |
| `GET` | `/api/meta` | Сводка: школа, время сервера, статистика, ссылка на бота. |
| `GET` | `/api/weeks` | Список учебных недель. |
| `GET` | `/api/directory` | Все группы, преподаватели, аудитории, предметы, периоды, «популярные». |
| `GET` | `/api/search?q=` | Поиск по справочнику. |
| `GET` | `/api/schedule/{kind}/{id}` | Расписание на неделю. `?week=<номер>` или `?day=ГГГГ-ММ-ДД`. |
| `GET` | `/api/now/{kind}/{id}` | Текущая и ближайшая пара. |
| `GET` | `/api/offline/{kind}/{id}` | Компактный пакет всех недель для офлайн-кэша. |
| `POST` | `/api/refresh` | Ручное обновление (нужен `X-Admin-Token`). |
| `GET` | `/api/refresh/status` | Состояние последнего обновления. |

`{kind}` — одно из `class`, `teacher`, `room`.
`{id}` — идентификатор EduPage, например `*98` (IT1-26); URL-кодируется.

## Как работает офлайн

Требование — открыв приложение один раз с интернетом, дальше видеть расписание
даже без сети.

1. **Оболочка.** Service worker (`web/sw.js`) кладёт в `Cache Storage` HTML, CSS, JS,
   шрифты и иконки. Повторный запуск отдаётся из кэша мгновенно.
2. **Данные.** Справочник (`/api/directory`) и метаданные (`/api/meta`) сохраняются в
   `localStorage`. Расписание группы — целиком во все недели — кладётся в
   `localStorage` (ключ `ttpu.bundle.v1.class.<id>`) после первого открытия или по
   кнопке **«Сохранить офлайн»**.
3. **Поведение без сети.** Интерфейс читает `localStorage`; если сети нет — рисует
   сохранённое расписание и показывает плашку «Офлайн · данные от …». «Сейчас идёт»
   и «Далее» считаются локально, поэтому работают и без сервера.
4. **Страховка на уровне сети.** Запросы к `/api/offline/*` идут по стратегии
   *network-first* с откатом в `Cache Storage` — на случай, если `localStorage`
   очистили, а сеть пропала.

Проверить вручную: откройте приложение, выберите группу, включите режим полёта и
перезагрузите страницу — расписание останется на месте.

## Откуда берутся данные

Парсер работает напрямую с публичным JSON-API EduPage — **без Playwright и браузера**.

Все запросы — `POST` на `{EDUPAGE_ORIGIN}/timetable/server/<endpoint>` с заголовком
`Content-Type: application/json; charset=UTF-8` и телом:

```json
{"__args": [null, 2026], "__gsh": "00000000"}
```

| Endpoint | `__args` | Что возвращает |
|---|---|---|
| `ttviewer.js?__func=getTTViewerData` | `[null, <год начала учебного года>]` | Список учебных недель (`tt_num`, даты, `default_num`). |
| `regulartt.js?__func=regularttGetData` | `[null, "<tt_num>"]` | Таблицы одной недели: уроки, группы, преподаватели, аудитории, предметы, периоды. |

Особенности, на которые легко наступить:

* Форма `application/x-www-form-urlencoded` возвращает `{"reload": true}` — нужен именно JSON.
* `datefrom` учебной недели — **воскресенье**; `dateto = datefrom + 6`. Учебные дни —
  понедельник…суббота, поэтому «понедельник» недели = `datefrom + 1 день`.
* Дни кодируются битовой маской; в одной ячейке может быть несколько подгрупп
  (например, суббота разбита на Group 1 / Group 2 с разными аудиториями).
* Список недель меняется: прошедшие недели EduPage убирает. Приложение всегда
  показывает то, что отдаёт источник.

Хранилище — **денормализованный SQLite**: одна строка на
`(неделя, вид владельца ∈ class|teacher|room, владелец, день, пара)`. Так один и тот
же урок доступен и группе, и преподавателю, и аудитории без JOIN-ов на чтении.

## Docker

```bash
docker compose up --build -d
```

Приложение: <http://localhost:8000>. Данные (SQLite) лежат в томе `ttpu-data`.

Через `docker run`:

```bash
docker build -t ttpu-timetable .
docker run -d --name ttpu -p 8000:8000 \
  -e BOT_TOKEN=123456789:AA... \
  -e BOT_USERNAME=your_bot \
  -v ttpu-data:/app/data \
  ttpu-timetable
```

Для работы бота в контейнере достаточно переменных окружения — вебхук не нужен.

## Тесты и проверки

Скрипты лежат в `tests/` и не требуют фреймворка вроде pytest.

```bash
python tests/check_parser.py     # разбор одной недели напрямую из EduPage
python tests/test_api.py         # все /api/* через TestClient
python tests/test_bot.py         # тексты, клавиатуры, «ближайшая пара», хранилище
python tests/shoot_web.py        # скриншоты экранов (нужен playwright)
```

`shoot_web.py` требует запущенного сервера и установленного Playwright:

```bash
pip install playwright
playwright install chromium
python main.py            # в другом окне
python tests/shoot_web.py
```

## Структура проекта

```
main.py                     точка входа (uvicorn + бот)
turin/
  config.py                 настройки из .env
  edupage.py                клиент и парсер EduPage
  db.py                     схема SQLite, запросы, справочник
  sync.py                   скачивание, запись в базу, планировщик
  schedule.py               «сейчас / далее», сетка дня, офлайн-пакет
  api.py                    FastAPI: /api/*, отдача SPA
  bot/
    runner.py               запуск polling, регистрация команд
    handlers.py             команды и callback-и
    keyboards.py            инлайн-клавиатуры
    texts.py                шаблоны сообщений
    notifier.py             утренний дайджест и напоминания (тик 25 с)
    storage.py              пользователи и подписки (SQLite)
web/
  index.html                разметка всех экранов
  assets/app.css            дизайн-система
  assets/app.js             маршрутизация, офлайн-кэш, i18n, «сейчас/далее»
  assets/fonts/             самохостные woff2 (Literata, Manrope, JetBrains Mono)
  sw.js                     service worker
  manifest.webmanifest      PWA-манифест
scripts/                    генераторы шрифтов и иконок
tests/                      проверки и скриншоты
data/                       база расписания и пользователей бота (git-ignored)
```
